uBase packet guide

A uBase packet (.ubase, format wave.ubase/2) is a zip that adds one feature to a Base44 app. Bots: read the guide, build the packet, run the checker with --strict, and ship only with 0 errors.

  • SKILL.md: the guide (also installable as an agent skill)
  • check_packet.py: the checker (Python 3, no installs): python3 check_packet.py --strict my-packet.ubase
  • example/digital-clock.ubase: a packet built by a bot from this guide
  • index.json: versions and fingerprints, for machines

Install and submit packets at ubase.tech.
